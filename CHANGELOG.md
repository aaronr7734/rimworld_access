# Changelog

Notable changes to RimWorld Access, newest first.

Older changes (before version 2.0) are in the [pre-2.0 changelog archive](https://rimworldaccess.com/reference/changelog-archive/).

## [2.0 RC 3] - 2026-10-03

This quick patch fixes a few bugs and improves the new global logging feature introduced in the last patch.

### Added

- Pressing Enter on a log entry now jumps to the pawn in it. When an entry names more than one pawn, a menu asks which one.

### Changed

- The global log is now two logs, social and combat, one tab each. Left and Right Arrow switch between them, and each log keeps its own filters, so the combat log can show everyone on the map while the social log sticks to your colony.
- The medical defaults window, opened from the Assign tab's medical care menu, now reads as a table. Each group is a row and each care level is a column, so you can hear every group's setting and change it with Enter.

### Fixed

- Fixed the meme picker leaving out memes from mods that add a fourth, extreme impact level, such as Alpha Memes.
- Fixed wild men showing the Tame column as not applicable in the wildlife menu, so they can now be marked for taming from there.


## [2.0 RC 2] - 2026-09-29

### Added

- Adaptive Storage Framework storage now has a full Contents list. Each item reads its mass and days until it rots. You can also change the stack limit, allow or forbid items, and drop them.
- Caravan formation, caravan splitting and transport pod loading are back to the classic lists by default. Every row now reads what the game shows beside it, like mass, value and rot time. Press Ctrl+Tab (Option+Tab on a Mac) to switch to the table view.
- Added the global log, opened with Alt+L or from the F12 menu. It lists every social and combat event in the world and goes back much further than the game's own log. You can filter it, search it by typing, and jump to the pawns in any entry.
- With Vehicle Framework, the split caravan window now has a Vehicles tab. You can split vehicles off a caravan and assign their seats.

### Changed

- Changing a pawn's autopilot settings no longer cancels an order you just gave. The pawn finishes that order first. Engage orders still take effect right away.
- The flight recorder no longer logs every frame while a menu is open, so recordings are much shorter.

### Fixed

- Fixed the control type and state announcement settings turning themselves back on after restarting the game.
- The caravan info screen now gives locations as a biome and map coordinates instead of tile numbers. Southern and western coordinates also read correctly now.
- Fixed Shift+Enter on a caravan or pod row pressing Send. It now takes as much as you can carry. Alt+I on the split caravan's pawns tab also opens the right info card now.
- Fixed the caravan formation and split caravan windows going blank on screen while you were on their buttons. Vehicle rows also read their speed, cargo capacity and value now.
- Fixed the Contents tab on caskets, portals and other containers only reading a summary. It now lists each item. Alt+I opens an item's info card.
- Fixed the Change route button in caravan formation being silent. It now tells you that you are choosing a route.
- Fixed painting a combat policy of None down the Assign tab, which used to skip every pawn.
- Fixed editing a drug policy. You can now change every setting right in the drug table.
- Fixed info card rows like an animal's sex or category reading their value twice.
- Fixed the inspection panel staying on a construction frame after it finished. It now moves to the finished building.
- Fixed a menu item with no description reading the description of the item above it.
- Fixed transport pod launches announcing two different ranges. You now hear one range, set by the pod with the least fuel.
- Fixed the scanner lagging on big maps, especially while the game is running.
- Fixed the inspection panel misbehaving with storage mods that open the Contents tab on their own, like Adaptive Storage Framework. You can leave that mod setting on.
- Fixed an error at startup with Vehicle Framework installed. Vehicle autopilot moves also say what they are doing again.
- Fixed a vehicle on search and destroy getting stuck when it reached the enemy. It now stops and fights from where it is.


## [2.0.0] - 2026-09-14

Version 2.0 is a rebuild of RimWorld Access from the ground up.

Screens are far more consistent than they were. The same keys and the same announcement grammar carry across the main menu, world creation, every tab, every dialog, and most third-party mod screens.

You can also always reach a screen's buttons. The game's toolbar is shown on every screen and Tab will eventually carry you to it, so you should no longer get stuck wondering which key moves you forward.

Menus and dialogs are now the game's real windows instead of invisible copies, so they appear on screen exactly as the game draws them. Someone watching can see where your cursor is, and can use the mouse alongside you.

Some popular mods now have dedicated support, and mods without it are covered by a reader that handles most windows on its own.

Also new: text the game only shows under the mouse pointer is now spoken, developer mode is fully accessible if a little clunky, there are five new languages, and an optional mouse mode reads whatever the pointer touches.

Behind the scenes, rebuilding how one screen works went from about three days to about twenty minutes, so screens should improve a lot faster from here.

### Added

- Many popular mods now have dedicated support. [Character Editor](https://steamcommunity.com/sharedfiles/filedetails/?id=1874644848) got the most work: the whole editor is a proper screen, covering appearance, health, needs, social, inventory, genes and xenotypes, the browsers, presets, and the def editor. Also supported: [RimWorld Together](https://steamcommunity.com/sharedfiles/filedetails/?id=3005289691), [Colony Manager Redux](https://steamcommunity.com/sharedfiles/filedetails/?id=3310027356), [Vehicle Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=3014915404), [A RimWorld of Magic](https://steamcommunity.com/sharedfiles/filedetails/?id=1201382956), [Simple Sidearms](https://steamcommunity.com/sharedfiles/filedetails/?id=927155256), the Vanilla Expanded mods, Hospitality, RimTalk, Interaction Bubbles, Allow Tool, Alpha Memes, Dubs Bad Hygiene, the Progression mods, and anything built on JecsTools, HugsLib, or XML Extensions. The experience may not be as nice as the vanilla game experience, but I've done what I can. I can't play every mod out there, nor do I have the money to fix them all, but tools will be coming soon so mod builders can add accessibility for their own mods. Stay tuned!
- Mods without dedicated support are now covered by a generic window reader. It makes settings pages, dialogs, and custom windows navigable, and it recognizes every element type RimWorld supports, and a few others too! Page Up and Page Down jump between a page's sections, and disabled controls say why they are disabled. It is always on, and dedicated support simply takes over where something better exists.
- Inspection tabs added by mods are now readable and usable, on pawns, buildings, items, and zones. Buttons activate, checkboxes toggle, sliders adjust or take a typed value, and text fields edit. Tabs also gained an "Also shown on this tab" section, listing anything the visual tab draws that the accessible version does not.
- Text the game only shows while the mouse rests on something is now spoken. Character card entries, ideoligion rows, transfer lists, the quests tab, pawn summaries in the work and animal tables, meme details, and stat entries all read their explanatory text with the row it belongs to. Installed mods get the same treatment. Bare icons are no longer silent either, and labels cut short by a narrow column now read in full.
- Anyone watching your screen can now follow along. The map cursor is drawn as a highlighted cell, every screen outlines the row or cell you are on and scrolls it into view, keyboard placement draws the same preview a mouse drag shows, targeting draws its range circle, and the research tree scrolls to the project you are reading. Since dialogs and menus are now the game's real windows, a sighted person can also just use the mouse alongside you.
- The trade window now has two views, and Ctrl+Tab switches between them on the open window with your choice remembered. The classic view is the three-list design that has always been here, holding the trader's goods, the pending deal with its running balance, and your goods, moved between with Left and Right. The new one is a table view laid out the way the game itself draws the trade screen. Some testers found the table harder to get around, so classic is still the default, and there is a Default Trade View setting in Options. Both views share the same reading and editing: each row reads its name, what you have queued, both prices with the game's own good-deal and bad-deal wording, and the running total, and Enter opens the quantity chooser, where Up and Down step by one, Shift or Ctrl with the arrows step by ten or a hundred, and typing a number sets the amount.
- A new experimental mouse mode, off by default in Options. With hover speech on, whatever the pointer moves onto is read: controls and their tooltips, map cells with their terrain sounds, letters, the colonist bar, and the command bar. Clicking says what got selected, and drags speak their size and result. Two keys bridge the pointer and the cursor: Alt+J sends the pointer to your cursor, and Alt+Shift+J pulls your cursor to whatever the pointer is on. Alt+Shift+K makes the pointer follow the cursor continuously, and Alt+Shift+M toggles hover speech. Pointer movement is well tested on macOS and newly available on Windows and X11 Linux.
- A new Configure Spoken Announcements screen, the top item in Options under RimWorld Access. Every part of an announcement (name, shortcut, control type, control state, position, tree level, description, hints) can be switched off or reordered. Control type and state are separate parts, so you can hear the type like "checkbox" without the state like "checked", or reorder them independently. You hear each change as you make it, and Restore Defaults puts everything back. It is now the one place the announcement format lives, and every screen follows it right away.
- Five new complete translations: French, Turkish, Castilian Spanish, Brazilian Portuguese, and European Portuguese. Each covers every interface string and the in-game documentation, using the game's own official wording for that language. Simplified Chinese, Russian, Latin American Spanish, and Ukrainian are complete again and cover everything new in this release.
- Developer mode is now fully accessible. The debug action menu, debug output tables, the log window with full messages and stack traces, the inspector, tweak values, the def editor, and the map and world debug tools all read and work, with typeahead search throughout. With dev mode on, the mod also reads the extra detail sighted developers see, like exact hediff severities and world tile IDs.
- New: a combat autopilot for drafted pawns. Assign a combat policy and the pawn fights on its own; leave it on None and it only follows your direct orders. Abilities can be autocast, all at once or one at a time. A Pause checkbox suspends everything without losing the setup, and the checkboxes apply to your whole selection at once. What the autopilot is doing becomes the pawn's job, so cycling colonists or arrowing over a pawn tells you the tactic: "moving to cover", "holding position and firing", "attacking Raider". It is entirely optional, and a settings switch removes it completely. Drafted mechanoids, modded draftable animals, and Vehicle Framework vehicles are all supported.
- Combat policies are named sets of fighting behaviors, one checkbox each, managed in a real policy window just like drug or food policies. Assign them from the combat policy column in the Assign tab, or from the Animals and Mechs tabs for draftable pawns. Three presets ship: Full control, Fight nearby, and Stay safe. Every choice has a plain-language tooltip saying exactly what it turns on. Optional safety behaviors are part of a policy: keeping distance from melee attackers, falling back when badly hurt, and running clear of explosives. Retreats say why they happened, for example "badly hurt, falling back to 120, 45".
- Drafted pawns take three new kinds of order. Engage target sends a pawn after one specific enemy until it is down, available as a command or from the right-click menu on anything attackable. Search and destroy sends a pawn hunting hostiles on its own. Patrol (Shift+T) picks an area for a pawn to walk a beat in, stopping to fight anything that comes into range. A new Mark for attack designator on the Orders tab marks single targets or sweeps whole areas, and pawns on search and destroy go for marked targets first. Every autopilot command has a rebindable shortcut behind Shift, and each wears its own icon so they are easy to tell apart on screen.
- Drafted pawns can hunt. A Hunt animals checkbox on any drafted pawn makes it chase and kill wild animals the way sighted players hunt with drafted colonists. Hunting policies, managed like food and drug policies, decide which animals each pawn may go after, with a revenge-chance slider and a species filter. Two presets ship: Safe game and Any animal. Hunting stands down while any hostile threat is on the map.
- Pawn dialogue from Interaction Bubbles and RimTalk is now narrated as it happens, including lines you type as your colony's persona. Settings control whether it is announced, whether vanilla interactions count, and at what priority. A new Dialogue Log screen, on F12 when either mod is installed, lists every recorded line newest first and carries the related controls.
- Placing a building tells you much more. The notes the game draws beside the cursor are spoken as they change: which facilities the building would link to, how far the nearest one of its kind is, and substructure footprints. Areas with their own requirements, like the moving water a water mill needs, are described with size, direction, and whether the current spot will do. A temporary Placement spots scanner category lists the nearest positions where the building actually fits, closest first, and Home jumps you there with the rotation already set. In god mode, placement warns before destroying whatever is already there.
- The mod now tells you when it has updated. A What's New reader on the main menu presents the release notes you have not read yet, oldest first, with a link to the full changelog. The reader and the website are linked from the main menu and the pause menu, and a setting turns the popup off.
- The History tab is now covered in full, including the Graph page. Every recorder in every graph group (wealth, population, colonist mood, and any a mod adds) is summarized with its current value, range, and trend over the chosen dates, with a day-by-day drill-in. The Messages page now includes quest dialogs, caravan encounters, and narrative entries alongside letters.
- The credits screen, including the victory text after launching the ship or reaching any other ending, is now fully readable. It reads as one document with jumps between sections, the visible scroll follows your position, and skipping says so instead of just going quiet.
- Commands reach further. The inspection tree gained a Gizmos node carrying the same commands the G menu offers, each read as the control it really is, with disabled ones kept in the list along with the game's reason. Marking commands like Chop Wood, Mine, or Hunt now say how many things they marked. Enter works with Shift, Ctrl, or Alt held, for tools that change under modifier keys, and a tool's extra options open on the right bracket key.
- The research detail view now shows everything the game shows: tech level and exact progress, required benches, facilities, and techprints as their own rows with info cards, the unlocks the game itself computes, which mod or expansion the project comes from, and the dev-mode finish and techprint actions.
- Dozens of controls that used to be mouse-only now work from the keyboard. Among them: the auto-refuel checkbox on fuel gizmos, renouncing a royal title, the ideoligion hair, beard, and tattoo style editors, the xenotype icon picker, custom xenotypes in the starting-pawn picker, the mechanitor recharge threshold, quest reward preferences, the Work table's copy and paste column, the Mods screen's Workshop upload button, the saved preferred names list, and info cards for filter items, drug policies, and starting-pawn possessions.
- Gene rows now say what the game's own hover text says about conflicts. When several genes compete for the same slot, the one that applies reads as "active" and the others name the gene suppressing them, so a list of four skin colors no longer sounds like four equal choices. Genes the game picks between at random name the whole pool. A pawn's own gene rows now read complexity, metabolic efficiency, and the description too.
- Two new sounds. Moving the keyboard cursor plays the game's own soft mouseover click, because I love the game's UI sounds. And there is now, finally, a sound for when menus and screens wrap.
- The flight recorder now ships in the release build, for your bug reports. (There won't be any, of course, because RimWorld Access is perfect!) Press Alt (Option on a Mac) plus the game's screenshot key (F10 by default) to start recording from anywhere, and press it again to stop. It captures what the mod heard and said, never anything outside the game. When you stop, a dialog tells you where the file was saved with a button to open the folder. Attach that file to a bug report and we can see your exact session.
- Typeahead search in tables now finds columns, not just rows. Typing a column name, like "tame" in the Animals tab or a work type in the work table, moves you to that column and keeps you on the row you were on. Cell contents are searchable too, ranked below column and row names, so you can type a master's name and land on the cell that holds it.
- The game's color pickers, for allowed-area colors and lamp glow, are now full keyboard screens: a palette of named colors with Default and Darklight rows, Hue and Saturation rows standing in for the color wheel, a readback of the current and old color, and the real Cancel and Accept buttons. Shift+Enter accepts.
- Ctrl+C copies a colonist's work priorities and Ctrl+V pastes them onto another, in both the focused view and the table view.
- RimWorld Access can keep the game paused when it matters. New games start paused and quiet, opening the research screen from a finished-research popup stays paused, and the game stays paused after you close a trade. Each is a setting you can switch off.

### Changed

- Navigation is consistent within each kind of screen now, instead of being reinvented screen by screen. Several shapes remain, because the game's own interface has several: trees, tables, screens whose sections you move between with Left and Right, and screens whose sections you move between with Tab. What is shared is everything inside them. Every row announces the same way, in the order you choose. Checkboxes say checked or not checked and toggle with Space or Enter, dropdowns open on Enter, sliders and steppers adjust with Left and Right and accept a typed value, radio buttons select as you arrow onto them, tables read cell by cell under sortable headers, and disabled controls stay in the list and say why.
- You can always reach a screen's buttons. The game's own toolbar is now shown on every screen and Tab walks every button on it, so you should not end up stranded on a screen not knowing which key moves you forward. Shift+Enter presses the screen's next button from anywhere on it, whether that is Generate, Save, Done, or Accept. Enter on something that is not an interactive control names the button a second Enter would press, so you hear the consequence before committing to it.
- Dialogs and menus are now the game's real windows instead of invisible keyboard overlays. Confirmations, letters and choice dialogs, order menus, renaming, the options screen, save and load, the schedule table, bed assignment, and the pause menu all appear on screen exactly as the game draws them, with a highlight following your cursor. Because they are the real thing, they pause the game by the game's rules, play its own sounds, and take mouse clicks alongside the keys.
- Typeahead search is stronger everywhere. Multi-word queries work: pressing Space extends the search, so "left arm" finds the Left arm row, and shorthand like "ga pi" reaches gas pipe (thanks to Rashad's OniAccess mod for the pattern). Ranking favors the row you actually named, and a search reaches everything on screen including section headers and toolbar buttons. Home and End jump between matches without ending the search. Enter activates what the search found; Shift+Enter lands on it without activating, for when you want to hear where you are first.
- Map scanner improvements. Cycling categories now only recalculates the one you land on, so it is much faster on big or busy maps. Vehicles and other controllable units get their own category and their own section of the colonist bar. Things are sorted by the game's own data rather than by their label text, so modded races, debris, and buildings file correctly in every language. The scanner also keeps working while you pick a transport pod or shuttle landing spot. A category now reads its name and a real count, followed straight away by its first item: a group of twelve steel stacks counts as twelve, and destroyed things are not counted. Auto-jump is now a saved setting, so it stays on between sessions.
- Wherever the mod used to keep its own hand-written copy of something, it now reads the game's live data instead: the main menu, material menus, order menus, table columns, tab lists, scenario parts, and more. In practice this means content added by mods or by future game updates shows up automatically, in the same order sighted players see it, without waiting for RimWorld Access to catch up.
- Far fewer "tab" announcements. Opening a screen speaks the focused item directly, pressing Tab speaks the section's name and where you landed, and the word "tab" is now reserved for real tab strips, the way NVDA treats them. The optional count on entry says "2 sections" instead of "2 tabs". On a screen with only one section, Tab does nothing rather than re-announcing everything. Screens whose section names already tell you where you are, like the work tab's priority levels, no longer add "section 2 of 5" after them.
- Ctrl and an arrow key now has four jump modes instead of two, cycled with Shift and Up or Down. Preset distance is unchanged. The old "Adjacent to wall" is now Impassable, and Structure jumps to the next tile whose building differs, so a run of marble wall or a stretch of sand crosses in one press. A jump also says how many tiles it covered.
- Target sliders on command buttons now adjust with Left and Right directly in the command menu, with Shift for bigger steps, and each press applies immediately. The separate right-bracket adjustment mode is gone. Enter on these buttons still does what it always did. While the command menu is open, arrow keys belong to the menu alone and no longer move the map cursor underneath.
- Arrow keys that run into an edge now play a short tone instead of re-reading the row you were already on, anywhere navigation does not wrap. This covers rows, table columns, toolbar buttons, tree views, command menus, the colonist bar, and the work tab in both its views.
- Rename dialogs now submit when you press Enter after typing the new name, matching how the game behaves for sighted players. Shift+Enter also presses OK from anywhere in the dialog, and Escape still closes without renaming. Enter now expands and collapses read-only tree branches too, such as scenario parts and detail sections, instead of only re-reading them.
- Manage Areas is now the game's real dialog everywhere: the Animals, Mechs, and Schedule area pickers, the per-pawn area menu, and the architect area tools all open it. It reads as a table with one row per area and one column per control: color, expand, shrink, invert, rename, copy, and delete, each announced as the button it is. Inverting an area now reports the resulting size instead of the vague "All cells toggled".
- The learning helper got a round of work. It now opens with ? from any screen, including every world-generation step and while configuring an ideoligion, and Escape dismisses it. Its lesson-mode control is now a "Show all lessons" checkbox you flip with Space or Enter, matching the game's own plus/minus toggle, instead of a dropdown you had to open. Escape from a lesson's Mark Learned button now returns to the lesson list rather than closing the helper, and a lesson no longer marks itself finished and drops off the list the moment you reach its last line; it leaves the active list only once you step back to the lesson list.
- The ideoligion appearance editor now behaves like every other tree in the mod. Category rows like Minimal or Punk announce as expandable tree items, individual styles as combo boxes, Left on a style collapses its category, and the tree respects your submenu navigation setting.
- Arrowing down onto the buttons at the bottom of a reader screen, such as a letter, a quest, or the learning helper, no longer plays the tab-switch sound or announces a new section. The buttons read as a continuation of the text above them, so the whole thing feels like one strip. Tab still treats them as their own section where a screen offers that.
- The main menu's Tutorial button is now hidden for keyboard users, since RimWorld's built-in tutorial depends on mouse-only, exact-placement steps a screen reader cannot follow.
- Smaller changes: skill names are capitalized wherever they are read, matching the game; leaving placement mode with nothing pending says "Exited placement mode" rather than "Placement cancelled", making clear that confirmed work is kept; message and confirmation dialogs no longer prefix their text with the word "Description", and no longer announce "Dialog opened" first; menu rows that toggle something are now real checkboxes that keep the menu open; right-click and pop-up menus share the full search grammar; the Anomaly playstyle choices select on arrival like every other radio group; the storyteller page opens on the game's own fallback difficulty; and the flight recorder's saved-recording dialog is one clean button strip.

### Removed

- The text panels the mod used to draw over the screen are gone: the world map information box, the landing-site panels, and the placement instruction box. The game's own highlights and windows carry that information now, and nothing is spoken any differently.

### Fixed

- Speech no longer goes silent on Windows. Machines with AVX-512 processors were rejecting any announcement containing a non-ASCII character, so an accented letter, a curly apostrophe, or CJK text produced silence while plain English spoke normally. Announcements carrying stray invisible characters from mod content were dropped outright. Both are fixed, and any remaining speech failure now logs the exact text so it can be diagnosed from your log file.
- Actions now go through the game's own rules everywhere, closing a long list of cases where this mod could do something the game would refuse, or skip a warning it would show. Among them: drafting respects downed pawns and mech overseer range; taming and slaughter show their bond, faction, and veneration confirmations; surgeries respect availability and speak the game's reason when refused; caravan equipping shows the persona weapon warning; accepting a quest shows the royal favor warning; research honors benches, techprints, and prerequisites; bill counts follow each recipe's limits; and name fields cap at the lengths the game really accepts.
- Playing in a language other than English is far more reliable. Several features recognized things by matching English text on screen, including notification buttons, caravan destinations, stat breakdowns, scanner classification, and storage commands, and they broke quietly in translation. They now use the game's own internal names. Remaining hardcoded English was made translatable, names joined into lists follow each language's own word order, and spoken key names like Enter and Page Up translate too.
- Cycling colonists with comma and period no longer freezes the game when a connected display has no signal, a common setup for players who do not need the picture. Unity reports a garbage screen size in that case, which sent the game's own colonist bar layout into a loop with no way out. It is guarded now, and colonist cycling keeps working with no display attached.
- Fixed a crash to desktop during startup when an installed mod ships optional hooks into another mod that is not loaded, for example Progression: Core with VFE Tribals disabled. The tooltip scanner now skips anything it cannot safely inspect instead of taking the game down with it.
- One broken mod can no longer take the reader down with it. A mod shipping an assembly that will not load on your platform used to silently disable command announcements for the whole game, and an error inside a screen's reader support left a silent window swallowing keystrokes. Both now contain themselves: the offending piece is skipped, or the screen says it failed and steps aside.
- A family of focus bugs is gone, where a window opened from another screen came up buried underneath it, unreadable, with Escape closing the wrong thing. Naming a newborn from its birth letter, a confirmation from the Animals table, and an info card from the Factions tab were all affected. Windows opened from anywhere now speak and take input, and dialogs that pop up on their own, like the debug log after a mod error, no longer silence whatever is underneath.
- Escape while editing a text field on one of the new game pages now only cancels the edit. Cancelling a colonist's name used to back out of the page underneath as well, and sometimes the page before that too. Enter behaves the same way: confirming a seed or a name finishes the edit without also advancing to the next page.
- The xenotype editor and gene assembler got a round of repairs. Toggling a gene no longer collapses every category and throws the cursor to the top. Loading a xenotype now refreshes the selected-genes list and gene library immediately, and uses the same accessible file list as saving a game, with Delete removing a file after a confirmation. Collapse all and Expand all now move the categories the screen reader navigates too, and categories visibly open and close on screen. The unlabeled "..." button announces itself as "Name suggestions". Shift+Enter presses Save and apply, and Delete removes the focused gene. Save and apply now confirms the character was regenerated and reads their new details, matching the change a sighted player sees.
- Columns that mods add to the Animals, Wildlife, and Mechs tables used to announce their cells as unavailable. They now read generically whenever the mod's column is built on a standard game column type, including each cell's tooltip. Enter also works on those cells now, so a dropdown column a mod adds opens its menu. The Traits column from Animal Traits System reads every animal's traits with their full descriptions, and the Spare Traits column says whether an animal is protected from auto-slaughter or marked for cull.
- Empty screen sections no longer trap you outside them. Entering an empty list, such as the mods screen's disabled column when every mod is enabled, used to throw the cursor into another section and drop the empty one from the Tab cycle. Empty sections now stay reachable with Tab and announce themselves as empty.
- Some mods add a search box to a dialog and hand it the keyboard the moment the dialog opens. That box then swallowed every arrow key and the dialog went completely silent; the bed assignment window from Sensible Bed Ownership was the first confirmed case. The mod now keeps the keyboard on every dialog it drives, whatever a mod focuses. Typing a name in that window jumps to the colonist, and Tab moves between the list and Close.
- Acting on letters no longer discards them. Jumping to a letter's location or viewing its quest leaves refugee, visitor, birth, and other offer letters in the stack until you actually answer them, matching how the game itself treats each kind.
- Forming a caravan from the world map no longer reads out the caravan dialog before it appears. The game hides that dialog while you pick a destination on the planet, so the mod now stays quiet about it until the route is confirmed and the dialog is really on screen.
- In the precepts editor, setting or removing a precept keeps the cursor in the section you were working through and moves it to the next issue there, instead of following the issue into its new section. The announcement still says where the issue went, and the cursor only follows when the section you were in has emptied.
- The pawn filter's reroll no longer strips what other mods give pawns at creation. The fast reroll loop rebuilt candidates without ever calling the full generator, so mods that hook it never ran: with Intimacy's Gender Works enabled, a health filter produced starting pawns the mod treats as sterile. When any mod hooks pawn generation, the reroll now regenerates each candidate through the same complete pipeline as the Randomize button. Searches run a little slower in heavily modded games.
- Buttons that jump you to a thing's inspect tab now open the inspection tree with your cursor already on that tab's section. This covers vanilla's own jumps, like a death letter opening the combat log or a character card's social link, and mod buttons like Character Development's character rows; they used to open the tab visually and announce nothing. A button inside an inspect tab that opens a different main tab, such as Character Development's Add quirks, now opens that tab and hands it the keyboard, instead of bouncing back to the inspect pane or opening behind the tree. The tree keeps its place and returns when that tab closes.
- Character Development's Characters tab is much improved. Enter on a character opens it for inspection with the cursor on their Wants section, instead of closing the tab and dropping you back on the map in silence. The tab now follows the mod's per-pawn reward points setting, so rewards no longer read as unavailable, each character's own points are spoken, and characters holding points with no wants are listed. Its Wants inspect tab reads properly too: the points bar is no longer three bare numbers, and every want and quirk is its own entry carrying its description and reward, with actions to reroll a want, dismiss it, add quirks, or remove one.
- Progression: Education reads correctly now. Its Education tab reads the empty-class message, the classrooms description, and each classroom's color; the Knowledge panel reads a proficiency track even before a pawn has been granted a tier; and Enter no longer also creates or saves the class while you are assigning a teacher or student in its dialogs.
- Form controls on a mod's own dialog now reach you complete. In the Additional controls section, a control with a very short label could be dropped, and a control drawn with its name beside it could arrive unnamed. Progression: Education's class dialog showed both, losing its subject picker and class hours outright and leaving its name, skill, and classroom fields unnamed. Nothing is dropped now unless we are certain it is already spoken elsewhere.
- A slider whose ends are labelled with its own minimum and maximum now reads as a slider with a value, instead of reading those end labels as its name and setting. Progression: Education's semester goal slider announced "1,000 xp, slider, 100,000 xp" no matter where it was set, which made the target look like something that could not be changed.
- A button that opens a mod's own window from one of our full-screen readers now hands that window the keyboard. Vanilla Factions Expanded - Tribals' Cornerstones button on the Factions screen was the clearest case: the window opened and read itself, but every key afterward still went to the faction list behind it. This is fixed for every screen at once, for any mod window that does not declare itself a modal dialog. The Tribals cornerstones window also announces your faction name and tells you the new ethos when unlocking a cornerstone rewrites it.
- In the classic trade view, Enter on an item now opens the quantity chooser instead of arming the Accept confirmation. The Default Trade View and Default Work Menu View setting descriptions were rewritten for clarity, the classic view description no longer wrongly says Tab moves between the lists (it is Left and Right), and each view's description is read aloud when you open the picker to choose one.
- Quieted spurious startup errors. The harmless missing-texture errors logged when playing without the Biotech DLC are gone, and errors on the storyteller selection page when another mod rewrites it are now warnings in the log rather than errors read aloud.
- A batch of smaller fixes: opening a drug's settings in the drug policy manager reads each row as the checkbox, stepper, or slider it is instead of repeating the drug's name; drawing a straight line with the empty rectangle shape counts its cells once rather than twice; picking a new thing to build from a blueprint's gizmo menu right after placing something now places what you picked, not the previous building; the research tree moves a project into In progress once you start it instead of leaving it stuck under Available; saving your game returns you to the game rather than stranding you in the pause menu; and Page Up and Page Down on a starting character's skill land on that same skill for the next or previous character instead of jumping to the top of the list.
