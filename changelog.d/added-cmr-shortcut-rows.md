Colony Manager shortcut rows (All, Predators, Stone and so on) now come straight from the mod, so every shortcut it offers is there, including the newer ones like Insects, Venerated, Medicinal plants, Deep minerals and the Mining building categories. Ctrl+Enter allows only a row's options, Shift+Enter also allows them, and Alt+Enter stops allowing them, just like the mod's modifier clicks (Command+Enter on a Mac).
