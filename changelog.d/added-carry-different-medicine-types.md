[Carry Different Medicine Types](https://steamcommunity.com/sharedfiles/filedetails/?id=3014295064) is now supported. The Assign tab's Carry column lists each medicine a colonist carries and how many, Enter opens the mod's medicine window, and copying or painting the column copies every medicine. In the medicine window, each slider is named after its medicine. The same fix names value-only sliders in other mods' windows that put the name to the left.
